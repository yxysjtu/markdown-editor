这些字体是 `article` 模板用的，从 Latin Modern（LaTeX 默认字体 Computer Modern 的 OpenType 版本）裁剪而来：

- 只保留了西文字符（拉丁字母、常用标点和符号），转成 woff2，每个文件约 40 KB。
- 字体里的名字改成了 Article Roman、Article Title、Article Mono，表明这是改过的版本。
- 原字体由 GUST e-foundry 制作，按 GUST Font License 发布，许可证见 `GUST-FONT-LICENSE.txt`。

| 文件 | 原字体 | 用途 |
| --- | --- | --- |
| `article-roman-regular.woff2` | lmroman12-regular | 正文 |
| `article-roman-bold.woff2` | lmroman12-bold | 粗体、标题 |
| `article-roman-italic.woff2` | lmroman12-italic | 斜体 |
| `article-roman-bolditalic.woff2` | lmroman10-bolditalic | 粗斜体 |
| `article-title-regular.woff2` | lmroman17-regular | 文章题目 |
| `article-mono-regular.woff2` | lmmono10-regular | 代码 |
